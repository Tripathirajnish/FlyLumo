FARES HUNT V5.3 — Airline logo files

Create this folder in your Laravel project:
public/mail_images/airlines/

Then place PNG logos using these exact filenames:

Behavior:
- If the matching PNG exists, the email displays it.
- If it does not exist, the template displays the airline code badge instead.
- The mapping first checks explicit airline-code fields from the API.
- If those are absent, it extracts the code from flight numbers such as AA-2917, UA57, or F9-1483.
